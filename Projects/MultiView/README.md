# MultiView

Data for the MultiView native sample (`Source/Samples/MultiView`), not an editor project.
The sample loads `MultiView.wonproj` from this path, so don't rename or move the folder.

One scene through four views in a 2x2 split. Each view picks its camera by `viewer_index` (0-3)
and runs its own sequence, cutting to a static camera near the end.
